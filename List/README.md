A list in Python is one of the most commonly used data structures. It’s an ordered, mutable collection that can hold elements of different types (integers, strings, objects, even other lists).

🔑 Key Features of Lists
Ordered → Elements maintain the order you insert them.

Mutable → You can change, add, or remove elements.

Heterogeneous → Can store mixed data types.

Indexing → Supports positive and negative indexing.

Slicing → Extract sublists easily.
