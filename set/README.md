A set in Python is an unordered collection of unique elements. Unlike lists or tuples, sets automatically remove duplicates and don’t preserve order. They’re very useful when you need to ensure uniqueness or perform mathematical operations like union, intersection, and difference.

🔑 Key Features of Sets
Unordered → No guaranteed order of elements.

Unique elements → Duplicates are automatically removed.

Mutable → You can add or remove items.

Fast membership tests → Checking if an item exists is very efficient.
