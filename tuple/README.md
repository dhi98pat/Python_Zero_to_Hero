A tuple in Python is very similar to a list, but with one key difference: tuples are immutable. That means once you create a tuple, you cannot change, add, or remove its elements. Tuples are often used when you want to store a fixed collection of items that should not be modified.

🔑 Key Features of Tuples
Ordered → Elements maintain the order you insert them.

Immutable → Cannot be changed after creation.

Heterogeneous → Can store mixed data types.

Indexing & Slicing → Works just like lists.

Faster than lists → Because they are immutable.
