In Python, a variable is simply a name that refers to a value stored in memory, and you create one using the assignment operator =.

Definition: A variable is a symbolic name pointing to a value (object) in memory.

Declaration: Use variable_name = value.

Dynamic Typing: The type is inferred automatically; you can reassign a variable to a different type later.

Naming Rules:

Must start with a letter or underscore (_), not a digit.

Can contain letters, digits, and underscores.

Case-sensitive (myVar ≠ myvar).

Cannot use reserved keywords like class, if, else.
